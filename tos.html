1. Technical Information Collection

When interacting with certain elements on our application (such as clicking specific functional elements), our system collects limited, essential server-side logs. This automated metadata transmission captures your incoming IP address, action name, and an exact execution timestamp.

2. Purpose of Collection

We process this standard technical infrastructure info to actively enforce system safety, combat automated exploit loops, preserve stability, and fulfill system debugging analysis. No operational logs are relayed to third-party data handlers or user behavioral profiles.

3. Security & Retention

All captured interaction timestamps are protected via closed, access-controlled backend database storage layers.
